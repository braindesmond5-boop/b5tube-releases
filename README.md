# B5Tube for Android

Downloads for the B5Tube Android app. There is no source code here.

**Install:** open the [latest release](../../releases/tag/latest) on your phone, tap `b5tube.apk`, and allow installs from your browser when Android asks.

After the first install the app updates itself: it checks this page for a newer build and offers it inside the app (Android asks you to tap Install).
